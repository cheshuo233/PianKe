# 真机清单

每次发布逐条跑。设备：Redmi K90 Pro Max（K90），USB 已连，`adb devices` 能列出。结果记在末尾「首次运行」表里：通过，或现象加截图路径。

## 清单

1. **档位与长焦**：哪些档位留了下来，长焦（115 / 135 / 200 mm）能不能用。记下实测档位和 `CONTROL_ZOOM_RATIO_RANGE`；到不了的档位应当已自动消失。
2. **成片文件**：`DCIM/Pianke` 里的文件名（`PK_yyyyMMdd_HHmmss.jpg`）、EXIF（曝光时间、ISO、光圈、焦距、拍摄时间、Make/Model、ImageDescription 为胶片名、Software 为 `Pianke <版本号>`、Orientation 为 1）；竖拍有没有转正，日期在转正后的右下角；1:1 取的是中心正方形。
3. **取景与成片并排**：同一场景，比较取景（GPU LUT + 轻颗粒）和成片的色调、颗粒观感。
4. **杀进程后恢复**：拍 2 张后立刻 `adb shell am force-stop app.pianke`，重开后两张都在 `DCIM/Pianke`，`pending/` 清空。
5. **权限**：拒绝相机权限（显示「需要相机权限」和按钮）；再选「不再询问」（按钮变为打开应用设置页，授权后返回能直接取景）。
6. **反馈**：每一档变焦和每次换胶片的震动与 NOTCH 声；快门、过片、倒片（拍到第 36 张后）、拒绝各自的震动与声音；静音模式下只震动不出声；MENU 开关的 NOTCH。
7. **冲洗时间和内存峰值**：每张的冲洗耗时（logcat 或 `adb shell dumpsys meminfo app.pianke` 的峰值），3:4 与 1:1 各记一组。
8. **连按快门与满队列**（Review Focus 3）：
   - 快门快速连按：上一次 `capture` 没返回时不响应，不多拍；
   - 队列里已有 2 帧时再按：播 REFUSE，不拍，计数不动；
   - 队列腾出位置后恢复正常，计数只在拍下后 +1。
9. **相机被占用与从后台返回**（Review Focus 4）：
   - 在另一个 App（如系统相机）里打开相机，再切回片刻：取景区显示「相机被占用」；
   - 另一个 App 释放相机后，取景自动恢复，提示消失（`issue` 清空）；
   - 按 Home 进后台再返回，取景恢复，不需要重开。
10. **变焦与后台返回**：拖到 115 mm，点相册缩略图（或按 Home、锁屏）再返回，取景的实际焦距仍是 115 mm（取景画面和上次一样大），刻度尺和取景角标仍是 115；再拍一张，EXIF 焦距为 115 mm 档。换到前置再换回后置，回到 23 mm。
11. **换卷抽屉**：
    - 点胶片行里当前那卷，抽屉从右边缘滑出，取景在后面压暗、继续实时显示；
    - 单手上下拨动跟手，快速一甩会惯性转几卷，停下时吸到一卷，不过冲，每过一卷一下轻震；15 卷首尾相接；
    - 惯性转动中手指一按，立刻停住；这时点某张标签，选中的正是那一卷（Review Focus 1）；
    - 点任意露出的标签：转到它，装上这卷，取景立即换色调，NOTCH，抽屉滑回；
    - 向右划、点抽屉外面、按返回键，都不换卷直接收回；
    - 拨动和开合不掉帧。
12. **触摸对焦**：
    - 后置、前置都试：点画面里一个近处物体和一个远处物体，清晰的位置跟着点击走（前置是镜像显示，点哪里就对哪里）；
    - 对焦框奶白四角，对上时变橙并轻震，约 2 s 后淡出；连点时旧框被新框取代；
    - 1:1 画幅下点上下遮罩区不出框、不对焦；
    - 约 5 s 后恢复连续对焦（移动手机，画面会自己重新对焦）。
13. **仪式感**（把计数拍到第 36 张再拍一张；三档各试一次）：
    - 关：顶栏看不到计数鼓，拍照没有过片声和倒片声，第 36 张后也不倒片；
    - 中：第 36 张拍下后，计数鼓从 36 倒转回 1，倒片声加长震，取景压暗，LCD 显示 REWIND，约 1.5 s；这期间按快门没有任何反应，不拍、不播拒绝；之后快门恢复；
    - 高：先走一遍「中」，结束后抽屉自动滑出，顶部写「装一卷新胶卷」，右划、点外面、返回键都关不掉，选一卷后才收回；
    - 在第 36 张附近快速连按（Review Focus 2）：计数只从 36 变成 1 一次，之后不出现"拍不了"或少一个冲洗名额；
    - 倒片中按 Home，几秒后回来（Review Focus 3）：中档时快门已可用；高档时抽屉已滑出且关不掉；
    - MENU 里的三档滑块：拖动旋钮或点「关 / 中 / 高」都能换档，每换一档一下 NOTCH。
14. **任意变焦**（MENU →「变焦方式」切到「任意」）：
    - 拖动顺滑，能停在任意焦段，取景角标显示如「42mm · 1.8×」；
    - 每过一格刻度一下轻震，经过标数字的焦段（18 / 23 / 28 / 35 / 50 / 115 / 135 / 200）稍重一点；
    - 拖过两端：停在 18 或 200，到端点时一下 NOTCH，再往外拖不再震（Review Focus 4）；
    - 停在 42 mm 左右，回桌面再回来，焦距不变；
    - 停在 42 mm 左右，切回「档位」：变焦吸到 35 mm，不震；角标、变焦条、取景三者一致（Review Focus 5）。
15. **新变焦条观感**：浅色凸起外框、深色凹陷刻度窗在浅色页面上不突兀；当前焦段数字为红色，50 / 200 为琥珀色；左侧读数、右侧「18-200mm」清楚；整页上下不溢出屏幕。
